# 成語大冒險

小學中文成語及詞語溫習遊戲（單一 HTML，打開 `index.html` 即可玩）。

- 📘 功課紙範圍：課次 1、4、6、8 成語（20 個）＋ 33 個重點詞語
- 📗 五上 Term 1：四字成語（17 個）＋ 五上課本重點詞字（48 個）

- 🏰 第二章《亂字魔大鬧語文王國》：擬聲詞、量詞、複句、關聯詞、同音形近字（六年級語文工作紙三、五、六）

玩法：成語圖鑑、成語擂台（打怪獸）、詞語尋寶（不供詞填充）、錯字偵探、成績表及錯題簿。
第二章另有：聲音森林、墨墨雜貨店、郵差派信、關聯詞搭橋、錯字打地鼠，以及 15 日溫習日程。

DLC《修辭樂園》（六年級語文工作紙八、九、十）：變身魔術、比喻輸送帶、成語沖曬館、喚醒春天、變身門、回音谷、問號三兄弟、魔鏡同積木塔、誇張魔法棒、對比遊樂場、頂真火車，以及修辭過山車，收集 14 隻修辭精靈。
